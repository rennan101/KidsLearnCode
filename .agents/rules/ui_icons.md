# Antigravity Rules - UI & Aesthetics

## Iconography Guidelines
- **NEVER USE EMOJIS in UI buttons, menus, badges, labels, headers, or messages.**
- Use clean, scalable, modern **inline SVG icons** (Heroicons/Lucide style, `viewBox="0 0 24 24"` or `viewBox="0 0 20 20"`) for all UI actions, tools, headers, and tabs.
- Ensure all SVGs use `currentColor` for `stroke` or `fill` with appropriate width/height classes for seamless theming and crisp rendering.
