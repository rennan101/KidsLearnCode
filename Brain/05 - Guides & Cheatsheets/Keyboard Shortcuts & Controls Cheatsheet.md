## 🎮 Play Mode (Modo de Jogo)

| Tecla / Ação | Função |
| :--- | :--- |
| <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd> / Setas | **Movimento em Grid (Estilo Pokémon nas 8 direções)**: Passo a passo de 64px com interpolação suave |
| <kbd>E</kbd> / <kbd>Espaço</kbd> | **Interagir**: Conversar com NPCs, abrir desafios de blocos Lua, coletar ovos e itens |
| <kbd>B</kbd> | **Bolsa de Dragões**: Abrir menu rápido para selecionar companheiro, invocar ou montar dragão |
| <kbd>1</kbd> | **Esquiva Tática**: Comando em tempo real durante batalhas automáticas de dragões |
| <kbd>F</kbd> | Centraliza e trava a câmera imediatamente no Geralt |
| <kbd>M</kbd> | Abre / Fecha o Mapa Tático Expandido |
| <kbd>Esc</kbd> | Fecha o Mapa Expandido / Menus Sobrepostos |

## 🛠️ World Editor Mode (Modo Editor)

### Barra de Ferramentas Vertical (Photoshop / Illustrator Style)

| Tecla / Atalho | Ferramenta / Ação | Descrição |
| :--- | :--- | :--- |
| <kbd>V</kbd> | **Selecionar / Inspecionar** | Seleciona e inspeciona todas as camadas de uma célula |
| <kbd>B</kbd> | **Pincel (Brush)** | Pinta o asset selecionado com rotação e espelhamento |
| <kbd>G</kbd> | **Balde de Tinta (Fill)** | Flood fill para preencher áreas conectadas |
| <kbd>P</kbd> | **Ponto de Spawn** | Define o local exato de surgimento do Geralt |
| <kbd>C</kbd> | **Colisor (Collider)** | Edita caixas de colisão físicas com alças arrastáveis |
| <kbd>E</kbd> | **Borracha (Eraser)** | Apaga tiles (ou use o botão direito do mouse) |
| <kbd>I</kbd> | **Conta-gotas (Eyedropper)** | Copia o asset clicado no mapa para o pincel ativo |
| <kbd>R</kbd> | **Girar Asset (+90°)** | Rotaciona o asset do pincel em 90° no sentido horário |
| <kbd>H</kbd> ou <kbd>X</kbd> | **Espelhar Asset (Flip)** | Espelha horizontalmente o asset no eixo X |
| <kbd>1</kbd> | **Camada Chão** | Seleciona a Camada 1: `ground` (Água / Terreno) |
| <kbd>2</kbd> | **Camada Decoração** | Seleciona a Camada 2: `decor` (Flora / Detalhes) |
| <kbd>3</kbd> | **Camada Sólido** | Seleciona a Camada 3: `solid` (Estruturas / Base de Árvores / Barreiras) |
| <kbd>4</kbd> | **Camada Personagens** | Seleciona a Camada 4: `characters` (Geralt / NPCs) |
| <kbd>5</kbd> | **Camada Topo** | Seleciona a Camada 5: `overhead` (Copa de Árvores / Telhados / Acima do Player) |
| <kbd>Ctrl</kbd> + <kbd>Z</kbd> | **Desfazer (Undo)** | Desfaz a última ação (histórico de até 50 passos) |
| <kbd>Ctrl</kbd> + <kbd>Y</kbd> | **Refazer (Redo)** | Refaz a ação previamente desfeita |
| <kbd>F</kbd> | **Focar Geralt** | Centraliza a câmera no Geralt / Ponto de Spawn |
| <kbd>Scroll do Mouse (Roda)</kbd> | **Zoom In / Zoom Out** | Zoom suave e interativo centralizado na posição do cursor |
| <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd> | **Navegação Livre** | Pan suave e contínuo da câmera pelo mapa infinito |
| <kbd>Botão do Meio (Scroll)</kbd> | **Pan Manual** | Clicar e arrastar para mover a câmera livremente |
| <kbd>Botão Direito</kbd> | **Apagar Rápido** | Apaga tiles imediatamente na célula clicada |
| <kbd>Painel Câmera (Drawer)</kbd> | **Zoom Play Mode** | Ajusta o zoom global padrão da câmera do Play Mode (0.75x a 2.0x) |
| <kbd>Esc</kbd> | **Fechar Painel** | Deseleciona célula e fecha o inspetor |
